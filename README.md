# 💼 Sistema de Cadastro de Clientes

Projeto desenvolvido em Python utilizando SQLite para gerenciamento de clientes.

## 🚀 Funcionalidades

- Cadastro de clientes
- Listagem de clientes
- Busca por nome
- Atualização de cadastro
- Exclusão de clientes

## 🛠️ Tecnologias

- Python
- SQLite
- Git
- GitHub
- Visual Studio Code

## 📂 Estrutura

```
cadastro-clientes-python/

├── main.py
├── cliente.py
├── database.py
├── requirements.txt
└── README.md
```

## 🎯 Objetivo

Projeto criado para praticar conceitos de lógica de programação, manipulação de banco de dados e organização de projetos em Python.
